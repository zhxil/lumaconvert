# 轻转的交互取舍

使用场景是整理手机相册：用户关心能否保留回忆、画质是否足够、导出后是否还找得到文件。界面的焦点是文件队列和开始转换，检查结果时才打开对比窗口。

- 领域：原片、压缩、拍摄时间、相册层级、前后帧、输出位置。
- 颜色沿用现有相册工作台：雾灰底色、白色操作面、深色文字、灰色辅助文字、少量蓝色操作强调。照片自己的颜色居于主位。
- 对比是同一画面的一条分隔线；左右两侧共用平移和缩放。视频时间轴控制两侧同一时间点，采用帧预览，不声称同步视频播放。
- 左侧使用 NavigationView 真实页面导航，文件、任务和帮助各有内容页，不将导航入口实现成弹出菜单。不把 EXIF 或编码参数摆到主界面，不增加常驻说明段落。保留拍摄时间和文件夹结构默认开启，开关归于输出设置；细节留在工具提示中。
- 主界面只增加一个原生“压缩前后对比”按钮和结果摘要。已完成的文件即可对比，不必等待整个批次结束。
- 沿用 WinUI 原生按钮、滑块、下拉框和对话框，保留键盘与焦点行为。主体字号 14、辅助字号 12，控制区间距 12–16，轻边框与浅色底区分层级，不引入新的动效或组件库。
- 对比只加载选中项的一对预览，关闭即释放；高分辨率照片预览用 PNG，避免预览自身再增加 JPEG 压缩损失。预览最长边为 1536 像素，倍数表示预览缩放，不声称原片像素级无损查看。
- 文件夹导入保留选中的根文件夹及子目录；直接添加的文件输出到保存目录。路径提示随选中项显示，原片永不覆盖。
