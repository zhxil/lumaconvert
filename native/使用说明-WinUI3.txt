轻转 2.3 · C# + WinUI 3 版

运行
解压完整文件夹，双击 LightConvert.exe。所有文件应保留在同一个文件夹内。
本版面向 Windows x64（Windows 10 2004 及以上、Windows 11）。
已内置 .NET、Windows App SDK、HEIC 解码组件和 FFmpeg，不需要安装 Python 或 Windows SDK。

操作
1. 拖入文件或文件夹，或点击“添加文件”“添加文件夹”。文件夹会递归扫描。
2. 每行显示缩略图、格式和原始大小，选中后右侧显示预览；视频预览为首帧。
3. 选择压缩方式、保存位置，点击“开始转换”。
4. 每个文件显示当前阶段和进度，结束后显示输出大小及体积变化。
5. “打开目录”查看结果。“移除”“清空”只修改队列，不会删除文件。
6. 已完成项会跳过；失败和取消的项可再次点击开始重试。要用另一档重新压缩已完成文件，请移除后重新添加。
7. 失败原因显示在右侧；选择失败项可再次查看。

支持格式
HEIC / HEIF / JPG / JPEG / PNG → JPG
MOV / MP4 → H.264 视频 + AAC 音频的 MP4

压缩档位
清晰优先：JPG 质量 92，图片原分辨率；视频 CRF 20，原分辨率。
均衡压缩：JPG 质量 82、最长边 3840；视频 CRF 25、最长边 1920。
体积优先：JPG 质量 65、最长边 2560；视频 CRF 30、最长边 1280。
不会放大小图，视频边长可能为编码兼容调整至偶数。均为有损压缩，输出不保证比原文件小。

原文件保护
全程本地处理，不上传媒体。原文件不修改、不删除。
重名时自动另存为“名称_1”等。先写入独立临时文件，成功后才发布输出。
失败和取消会清理当前临时输出，已完成结果保留。
图片的取消会等待当前解码或写入阶段返回，视频取消会终止 FFmpeg 子进程。
缩略图解码在后台限并发运行，预览失败不影响尝试转换。
递归添加文件夹会跳过当前输出目录和目录链接，避免回收输出或循环扫描。

色彩和元数据
图片输出为 8 位 JPG，仅主图；不保留 Live Photo 关联、深度数据或 HDR 增益图。
有嵌入 ICC 的图片转换到 sRGB，移除 EXIF/GPS 等元数据；透明区域铺白。
视频保留第一条视频轨与第一条音频轨；HDR PQ/HLG 会转为 SDR。
Dolby Vision 动态元数据、空间视频、额外轨道和拍摄时间等元数据不保留。
本目录 7 张 HEIC、4 段 SDR HEVC MOV 样本已通过批量转换与完整解码验证。
真实 HDR / Dolby Vision 的色彩仍需原片目视确认；建议先少量试转。

本机设置
保存目录和压缩档位存于 %LOCALAPPDATA%\LightConvert\settings.json。
异常诊断默认写在同目录 crash.log；若目录不可写则尝试写程序目录 startup-error.log。
视频预览临时 JPG 在本机临时目录生成后立即删除；缩略图仅保留于内存。

验证
随附 verification 目录记录核心媒体转换与打包程序的 WinUI 批量运行结果。
包含 17 项核心生成样本验证及 11 份目录样本验证，不等同于 iPhone 全格式或 HDR 色彩验收。
拖拽数据通道经过 WinRT StorageItems 验证；跨进程鼠标拖拽手势另行人工确认。

源码构建
需要 .NET SDK 10、可访问 NuGet 的网络环境；项目通过 NuGet 恢复 Windows SDK 构建工具。
运行 native\build-native.ps1 -DotnetPath <dotnet.exe路径>。
运行 native\verify-native.ps1 可执行实际媒体集成验证。
bin\shared 需包含 FFmpeg 8.1 GPL shared 构建中的 ffmpeg.exe、ffprobe.exe 和全部 DLL。
此项目不调用 Python。旧 Python 源码与发布目录保留作为历史版本。
